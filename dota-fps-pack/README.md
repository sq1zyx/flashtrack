# Dota FPS Pack

Сборщик модов для Dota 2 по принципу Minify. Убирает тяжёлые **косметические** эффекты, чтобы поднять FPS и разгрузить картинку. Эффекты способностей, радиусы и всё, что влияет на геймплей, не трогаются.

## Что внутри

| Мод | Что делает |
|---|---|
| Без погоды | Убирает косметическую погоду (снег, дождь, пепел) |
| Без эффектов курьеров | Убирает шлейфы и ауры курьеров |
| Без эффектов вардов | Убирает свечение вардов, сами варды остаются |
| Без ambient-эффектов шмота | Убирает постоянное свечение косметики героев |
| Без декоративных эффектов карты | Убирает светлячков, пыль и листья |

### Ландшафт и карта (из Minify)

| Мод | Что делает |
|---|---|
| Тёмный ландшафт | Серо-тёмные плитки, тёмная вода, без тумана — герои и спеллы лучше читаются |
| Без кустов и камней | Убирает кусты, цветы, камни и прочий декор, деревья остаются. Сильно разгружает видеокарту |
| Без реки | Убирает воду, брызги и звуки шагов по воде |
| Без эффектов зданий | Свечение зданий/фонтана/аванпостов, снаряды башен, глиф, щит Терзателя, чучела |

Эти моды взяты из открытого проекта [Minify](https://github.com/egezenn/dota2-minify) (лицензия GPL-3.0, авторы — участники проекта Minify). Файлы скачиваются с GitHub при сборке и кэшируются в `cache/`, в этом репозитории их нет. Для «Тёмного ландшафта» и «Без кустов и камней» в инвентаре должен стоять **стандартный ландшафт**, а в настройках видео — **выключена трава**.

Мод Minify «Tree Mod» (деревья → маленькие кусты) сознательно не подключён: через него видно проходы между деревьями, а это преимущество в игре.

Список модов лежит в `mods.json`. Новый мод добавляется так: имя плюс регулярка по пути файла внутри `pak01_dir.vpk`.

## Меню

`run.bat` открывает тёмное меню с четырьмя вкладками:

- **Визуал** — галочки модов, сборка и установка пака, кнопка «Проверить» (сколько файлов найдено, без изменений).
- **Игра** — конструктор параметров запуска (Vulkan/DX11, лимит FPS, `-novid`, `-high`, `-language`): копирование или запись прямо в Steam (Steam должен быть закрыт, старый конфиг сохраняется в `localconfig.vdf.bak`). Запись `autoexec.cfg` (твои строки в нём не стираются) и шпаргалка по настройкам видео.
- **Система** — твики Windows с переключателями: схема питания, игровой режим, отключение Game Bar/DVR, Дота на дискретной видеокарте, высокий приоритет процесса, HAGS, отключение акселерации мыши, оптимизации во весь экран, сетевой троттлинг. Каждый твик откатывается, прежние значения хранятся в `backup.json`. Пункты с пометкой «админ» требуют кнопки «Перезапустить от админа».
- **Утилиты** — очистка кэша шейдеров (NVIDIA/AMD/DirectX/Steam), сброс DNS, выбор папки Доты, скан для мода плоского ландшафта.

## Как пользоваться (Windows)

1. Установи [Python 3](https://www.python.org/downloads/) с галочкой «Add to PATH».
2. Запусти `run.bat`. Путь к Доте найдётся сам через Steam.
3. «Визуал» → «Собрать и установить». Пак ляжет в `dota 2 beta/game/dota_russian/pak01_dir.vpk`.
4. «Игра» → «Записать в Steam» (или «Копировать» и вставить в Steam → Dota 2 → Свойства → Параметры запуска).
5. «Система» → «Применить рекомендуемые».

Консольный режим:

```
python build_pack.py --list                          # список модов
python build_pack.py --cli                           # собрать все моды
python build_pack.py --mods no_weather,no_courier_fx # только выбранные
python build_pack.py --dry-run                       # посчитать файлы, ничего не записывать
python build_pack.py --uninstall
python build_pack.py --scan                          # список файлов ландшафта → scan.txt
```

После крупных патчей пак лучше пересобрать: Valve иногда переименовывает файлы или ломает загрузку кастомных VPK.

## Дополнительно для FPS: настройки игры

Параметры запуска: `-language russian -vulkan` (если Vulkan тормозит или вылетает, замени на `-dx11`).

Настройки видео, которые сильнее всего влияют на FPS:

- **Качество рендера (Render Quality)** — 70–85%, почти незаметно, но даёт много FPS.
- **Тени** — выкл или минимум.
- **Ambient Occlusion, Ambient Creatures, Grass, Tree Wind, Atmospheric Fog** — выключить.
- **Качество текстур / эффектов** — среднее.
- **Max FPS** — выше частоты монитора (например, 240), без вертикальной синхронизации.

## Чего здесь нет и не будет

Ничего, что даёт преимущество в игре: радиусы мин и агро башен, ослабление или скрытие эффектов способностей, макросы. И никаких разблокировок платной косметики. Valve за такое банит.

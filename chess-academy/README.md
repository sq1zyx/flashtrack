# Шахматная школа «Дебют»

Приложение для обучения шахматам: дебюты с пояснениями к каждому ходу, тренировка по памяти, уроки, тактические задачи и игра с ботом-тренером.

## Что внутри

- **Дебюты** (19 линий): Итальянская, Испанская, Шотландская, Королевский гамбит, Ферзевый гамбит, Лондонская система, Английское начало, Сицилианская (Найдорф и Дракон), Французская, Каро-Канн, Скандинавская, Защита двух коней, Русская партия, Славянская, Староиндийская, Нимцович и ловушки (детский мат, мат Легаля).
  - «Изучение»: ход за ходом с объяснением (стрелки ← → на клавиатуре).
  - «Тренировка»: сыграй дебют по памяти, бот отвечает за соперника, есть подсказки.
  - Звёзды прогресса: ★ изучен, ★★ пройдена тренировка, ★★★ без ошибок.
- **Уроки**: ценность фигур, правила дебюта, вилка, связка, сквозной удар, мат по последней горизонтали, как найти хороший ход, эндшпиль.
- **Задачи**: 12 тактических задач с подсказками.
- **Игра с ботом**: 3 уровня силы, бот играет дебюты из библиотеки, называет дебют, оценивает каждый твой ход (книжный / хороший / неточность / ошибка / зевок) и подсказывает лучший ход.

Прогресс сохраняется в браузере (localStorage).

## Запуск

Без сборки и зависимостей: открой `index.html` или запусти `python3 -m http.server` в этой папке.

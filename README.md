# Sokolov.dev

Портфолио-сайт фрилансера: сайты и лендинги, Telegram-боты, вёрстка, карточки товаров для маркетплейсов.

🔗 **Демо:** добавь сюда ссылку после публикации через GitHub Pages / Netlify

## Структура

```
sokolov-site/
├── index.html      — главная
├── services.html   — услуги и как проходит работа
├── work.html       — примеры проектов
├── contact.html    — контакты
├── css/style.css   — общие стили
└── js/main.js      — копирование email в буфер обмена
```

## Технологии

Чистый HTML / CSS / JS, без сборки и зависимостей — можно открыть локально или разместить на любом статическом хостинге.

## Запуск локально

Просто открой `index.html` в браузере, либо подними локальный сервер:

```
python3 -m http.server 8000
```

и зайди на `http://localhost:8000`.

## Публикация на GitHub Pages

1. Залей файлы в репозиторий (в корень или в ветку `main`).
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<твой-ник>.github.io/<репозиторий>/`.

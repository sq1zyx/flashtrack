# Бот «Стол №8» — как запустить (≈15 минут, без программ на компьютере)

Всё делается в браузере. Токен бота никому не отправляй — даже мне. Ты сам вставишь его в Cloudflare как секрет.

## 1. Создай бота в Telegram
1. Открой **@BotFather** → `/newbot`.
2. Придумай имя (например «Мой стол 8») и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Скопируй его — он понадобится в шаге 4.

## 2. Создай хранилище (KV)
1. Зайди на dash.cloudflare.com → **Storage & Databases → KV** (или Workers KV).
2. **Create** → имя `stol8` → Create.

## 3. Создай Worker и вставь код
1. **Workers & Pages → Create → Create Worker** (шаблон «Hello World»).
2. Назови `stol8-bot` → **Deploy**.
3. Нажми **Edit code**, удали всё в файле `worker.js` и вставь содержимое моего `worker.js` целиком.
4. **Deploy** (справа сверху).

## 4. Настрой Worker (вкладка Settings)
1. **Bindings → Add → KV namespace**: Variable name `DB`, namespace `stol8` → Save.
2. **Variables and Secrets → Add** (тип **Secret**):
   - `BOT_TOKEN` — токен из шага 1;
   - `WEBHOOK_SECRET` — любая строка из латиницы и цифр, например `stepan2026secretXyz`.
3. **Trigger Events → Add → Cron Triggers** → выражение `* * * * *` (каждую минуту) → Add.

## 5. Подключи Telegram к Worker
Открой в браузере (подставь свой адрес Worker и свой WEBHOOK_SECRET):
```
https://stol8-bot.<твой-поддомен>.workers.dev/setup?key=stepan2026secretXyz
```
Если в ответе видно `"ok": true` и username твоего бота, всё подключено.

## 6. Пользуйся
Напиши боту `/start`. Он задаст 8 вопросов: подъём, уроки, автобус, зал, когда ты дома. После этого напоминания включатся сами.
Проверка напоминания: `/proverka`.

**Калории** — просто пиши боту, что съел, обычным сообщением:
`гречка 250, курица 180, 2 яйца, кефир` → он посчитает ккал и БЖУ и запишет.
Ошибся — `/otmena`. Сколько съедено — `/kkal`. За неделю — `/nedelya`. Калорийность продукта — `/produkt творог`.
Если продукта нет в базе — вручную: `/el 400 пирожное`.

### Необязательно: автобус по Яндекс.Расписаниям
1. Получи бесплатный ключ: yandex.ru/dev/rasp → «Получить ключ».
2. Добавь секрет `YANDEX_KEY` (как в шаге 4.2).
3. В боте отправь геопозицию 📍 рядом с остановкой и выбери её. Потом укажи номер автобуса: `/avtobus_nomer 123`. Проверка: `/avtobus`.

Честно: городских автобусов Москвы в Яндекс.Расписаниях часто нет. Тогда бот просто работает по времени, которое ты указал в `/avtobus 7:42 7`. Пробки и опоздания бот не видит.

### Необязательно: бот только для тебя
Узнай свой ID у @userinfobot и добавь секрет `ALLOWED_IDS` с этим числом.

### Вариант через командную строку (если удобнее)
```
npm i -g wrangler && wrangler login
wrangler kv namespace create DB      # вставь id в wrangler.toml
wrangler secret put BOT_TOKEN
wrangler secret put WEBHOOK_SECRET
wrangler deploy
```
Потом выполни шаг 5.

### Лимиты бесплатного Cloudflare
Хватает с запасом: 1440 запусков крона в день при лимите 100 000 запросов. Записей в KV — несколько десятков в день при лимите 1000.

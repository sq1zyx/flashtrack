# Телеграм-бот «Стол №8» — бриф и состояние проекта

Проект перенесён из чата в Claude. Код уже написан и протестирован локально (на моках).
Задеплоен: Cloudflare Worker `stol8-bot` (stol8-bot.sq1zyx.workers.dev), бот @remembership_bot, KV `stol8`.

## Кто и зачем
Пользователь — школьник 10 класса, Москва (Europe/Moscow, UTC+3).
Цель — спокойно снизить процент жира к последнему звонку в 11 классе (~май 2028).
Данные: рост 191 см, ~118 кг, ~30 % жира (ноябрь 2026).
Эндокринолог назначил **диету (стол) №8**. Подросток, ещё растёт, поэтому:
- никаких жёстких дефицитов, голодовок, пропусков еды;
- нормальный темп — не быстрее ~0,5–0,7 кг/нед; если быстрее — бот советует есть больше;
- срыв ≠ провал: тон поддерживающий, без стыда.
Уже делает: зал 3 раза в неделю (фул-бади), 11–13 тыс. шагов. Главная проблема — нет времени готовить.

## Калории (согласовано в чате)
- Миффлин—Сан Жеор: обмен ≈ 2300 ккал; ×1,55 (зал + шаги) ≈ 3550.
- Норма = расход − 500 ≈ **3050 ккал**, коридор 2900–3200.
- **Пол — 2700 ккал** (`KCAL_FLOOR`), ниже бот не опускает. Ручная цифра «от врача» — не ниже 2200.
- Белок от 150 г, жиры 85–100 г, углеводы — остальное. Это прикидка, финальную цифру согласует эндокринолог.
- Пересчёт по последнему весу; поправки `/kkal +200`, `/kkal -150` (−500…+800).

## Файлы
- `worker.js` — весь бот, один файл, без зависимостей (ES module для Cloudflare Workers).
- `wrangler.toml` — конфиг для деплоя через CLI (нужно вписать id KV).
- `README.md` — пошаговый запуск через браузер (BotFather → KV → Worker → секреты → cron → /setup).
- `test/test.mjs` — прогон команд, кнопок и крона по минутам на моках (`node test/test.mjs`).
- `test/yandex.mjs` — проверка выбора остановки и рейса Яндекс.Расписаний на моках.

## Архитектура
- `fetch`: `POST /webhook` (проверка заголовка `X-Telegram-Bot-Api-Secret-Token` = `WEBHOOK_SECRET`),
  `GET /setup?key=WEBHOOK_SECRET` — ставит webhook и меню команд.
- `scheduled`: cron `* * * * *` → для каждого пользователя строит события дня (`buildDay`) и шлёт те, что совпали с текущей минутой
  (плюс вчерашние с t ≥ 1440 — отбой после полуночи).
- KV (binding `DB`): `users` — массив chat id; `u:<chatId>` — один JSON со всем (настройки, еда за сегодня, вес, талия, фото, подходы).
  Без KV list, чтобы не упираться в лимиты бесплатного тарифа.
- Секреты: `BOT_TOKEN`, `WEBHOOK_SECRET`; необязательно `YANDEX_KEY`, `ALLOWED_IDS`.

## Что умеет
1. **Мастер настройки** (`/start`, `/nastroika`): подъём будни/выходные, начало уроков, время автобуса, минуты до остановки, номер, зал (дни+время), когда дома.
2. **Расписание**: подъём, зарядка (+10 мин), 4–6 приёмов пищи равномерно от подъём+30 до отбой−120;
   приём пищи подстраивается под «пришёл домой»; в день зала еда не ставится за час до тренировки и во время неё (переносится на зал+105).
   Отбой = подъём следующего дня − сон (по умолчанию 9 ч). Напоминания: за 30 мин до отбоя и в отбой. Будни/выходные, `/kanikuly`, `/pauza`.
3. **Питание**: напоминание с вариантом меню + кнопки «✅ Съел» (пишет ккал) / «🔁 Другой вариант»; `/menu`, `/zameny`, `/pokupki`, `/zagotovka`;
   заготовка вс 12:00 и ср ~19:00; `/el 350 б20 название`, `/otmena`, `/kkal`; поддерживающее сообщение при переборе > нормы+400;
   за час до отбоя — итог дня (ккал, белок); если отмечено < нормы−900, мягко просит не ложиться голодным; если пусто — напоминает записать. `/sryv`.
   **Подсчёт калорий текстом**: `FOODS` — база ~80 продуктов (ккал/БЖУ на 100 г, вес штуки `pc`, порция `d`, `ml` для напитков).
   Обычное сообщение «гречка 250, курица 180, 2 яйца, кефир» (или `/el ...`) → `parseMeal` → запись с БЖУ; что не узнал — подсказывает `/el 300 название`.
   Количество: граммы/мл/кг/л, «2 яйца», «2 куска», «стакан», «пол…», без числа — обычная порция. `/produkt гречка` — калорийность.
   История по дням `u.days` (60 дней) — `/nedelya`: калории за 7 дней, среднее, сколько дней в коридоре.
4. **Тренировки**: A (присед, жим лёжа, верхний блок, румынка, планка), B (жим ногами, жим сидя, тяга гантели, выпады, скручивания),
   C (гоблет, жим на наклонной, горизонтальный блок, мост, бицепс, трицепс). Ротация A→B→C при первой записи за день.
   Запись текстом: `присед 60x8 60x8 60x7`, `жим 50x10x3`. Подсказка прогрессии по диапазону повторов. `/trenirovka`, `/programma`, `/istoriya`.
5. **Прогресс**: вс — просьба взвеситься (`/ves`), 1-го числа — талия (`/talia`) и фото (сохраняется file_id). `/progress`: среднее за 3,
   темп кг/нед (регрессия за 7 недель) и совет; `/foto` — первое vs последнее.
6. **Автобус**: по времени пользователя (выход = автобус − идти − 2 мин, напоминание за 10 мин и «выходи»).
   С `YANDEX_KEY`: геопозиция → ближайшие остановки → выбор; при подъёме берёт рейс из Яндекс.Расписаний рядом с обычным временем.
   Честно предупреждает, что пробки не видит; городских автобусов Москвы в API часто нет.
   **Отслеживание**: событие `buscheck` за 30 мин до выхода — перепроверка рейса в Яндексе; если сегодня раньше/позже — уведомление с новым временем выхода.
   В «Выходи!» кнопки «🚏 Автобус пришёл» / «🚫 Уехал без меня» → `u.busLog` (diff факт−расписание); `busStats` (медиана по 10),
   `busEarly` — выходить раньше (до 5 мин), если автобус обычно/часто приходит раньше. Живых GPS-данных по Москве нет — их не обещаем.
   Обращение по имени из Telegram (`u.name` = first_name), без захардкоженного имени.

7. **Добавлено (ноябрь 2026)**:
   - Личный бот: KV `owner` (первый пользователь), `guests`; чужим — «личный бот» + уведомление владельцу; `/dostup`, `/dobavit`, `/ubrat`.
   - Фото еды → Workers AI (binding `AI`, `VISION_MODELS` с фолбэком) → JSON → сверка с `FOODS` → «✅ Записать». Подпись к фото помогает.
     Фото с подписью «форма/прогресс» — фото прогресса; без подписи — кнопки (еда / штрихкод / прогресс).
   - Штрихкод: фото (ИИ читает цифры) или цифры текстом → Open Food Facts → кнопки граммов / число.
   - `/moe` свои продукты (ккал на порцию), «🔁 Съел это ещё раз», `/povtor`.
   - Вода (цель 2500 мл, напоминания при отставании, «вода 500», `/voda`), шаги (вечером кнопки, `/shagi`, влияют на коэффициент активности 1,45–1,6),
     сон (кнопки в «Доброе утро»), вес кнопками в вс, таймер отдыха (`restAt`, крон), `/zamena`, `/grafik` (QuickChart),
     достижения + серия (`/dostizheniya`), итоги недели вс вечером (`/otchet`), `/eksport` CSV для врача,
     автоканикулы/праздники Москвы (`SCHOOL_HOLIDAYS`, `PUBLIC_HOLIDAYS` — примерные даты, `/kanikuly авто`).
   - Тесты новых функций: `node test/extras.mjs`.

8. **Мини-приложение + доработки**:
   - `app.html` → `node build.mjs` → `app.js` (импортируется в worker.js). Отдаётся на `/app`, кнопка меню «📊 Дневник» (setChatMenuButton).
     API `POST /api` {initData, action} — проверка подписи Telegram WebApp (`checkInitData`), `appState` отдаёт всё для экранов;
     действия: state, add (fi/g, mine/cnt, recent/g, text), edit, del, water, steps, weight, waist, sleep, set, unset, note, remind, quiet, timer, export.
     `/api/photo?f=&a=initData` — прокси фото прогресса. Экраны: Сегодня (кольцо, БЖУ, вода, вес, шаги, план еды), Дневник (поиск, правка граммов, удаление),
     Графики (SVG: вес со средней, калории, белок, сила, талия, вода, шаги), Зал (подходы степперами, таймер отдыха), Ещё (достижения, фото, заметки, напоминания, экспорт).
   - Голосовые: Whisper (Workers AI) → parseMeal / ИИ-разбор с подтверждением. Свободный текст, не найденный в базе → ИИ (`TEXT_MODELS`) → «✅ Записать».
   - `/dnevnik` — удаление любой записи; `/uzhin` и подсказка в напоминании об ужине — `smartMeal` (остаток делится на оставшиеся приёмы).
   - `/zametka` — самочувствие (в CSV для врача и отчёте). `/napominaniya` (группы `REMIND_GROUPS`, `u.off`), `/tishina` (кроме подъёма и автобуса).
   - Адаптивное время еды: `learnMeal` пишет разницу факт−план по слоту (`u.mealShift`), `buildDay` сдвигает на медиану (≥3 отметок, |≥10| мин, до ±60).
   - Тесты: `node test/app.mjs <папка>` — API + рендер в Chromium (скриншоты светлой/тёмной темы).

## Следующие шаги
1. Задеплоить (README или `wrangler deploy`), открыть `/setup?key=...`, написать боту `/start`.
2. Проверить напоминания в реальности (`/proverka`), поправить время/тексты по ощущениям.
3. Идеи на потом: напоминание о воде, учёт шагов, кнопки быстрого ввода веса, экспорт прогресса.

## Правила для правок
- Не добавлять целевые калории ниже `KCAL_FLOOR`, не советовать голодовки/пропуски еды, тон без стыда.
- Токен бота никогда не коммитить и не писать в файлы — только `wrangler secret put` / секреты в дашборде.
- После правок гонять `node test/test.mjs`.

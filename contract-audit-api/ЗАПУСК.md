# Запуск dogovor-audit.ru на своём компьютере

Инструкция для Windows 10/11. Для Mac и Linux всё то же самое, только вместо `start.bat` запускайте `./start.sh` в терминале, а туннель настраивайте командами из шага 6.

Что понадобится: компьютер, который может работать постоянно, интернет и примерно 2 ГБ свободного места.

---

## Шаг 1. Установить Node.js (5 минут)

1. Откройте https://nodejs.org и скачайте версию **LTS** (22 или новее).
2. Установите, на всех шагах нажимая «Next». Галочки оставьте как есть.

## Шаг 2. Скачать сервис (5 минут)

1. Откройте https://github.com/sq1zyx/flashtrack
2. Слева вверху переключите ветку (кнопка с названием ветки) на **`ccr-ad582537-78dti4`**.
3. Нажмите зелёную кнопку **Code → Download ZIP**.
4. Распакуйте архив, например в `C:\dogovor-audit\`. Нужна папка **`contract-audit-api`**: дальше всё делается в ней.

## Шаг 3. Получить ключ GigaChat (10 минут, бесплатно)

1. Откройте https://developers.sber.ru и войдите через Сбер ID.
2. Создайте проект **GigaChat API** — для физических лиц.
3. В настройках проекта нажмите **«Получить ключ»** (или «Сгенерировать ключ авторизации»). Скопируйте **Ключ авторизации** — длинную строку. Сохраните её: второй раз её могут не показать.

Названия кнопок в кабинете Сбера иногда меняются. Если что-то выглядит иначе, ищите раздел с «Authorization key» или «Ключ авторизации».

> **Важно — проверьте условия.** Бесплатный тариф для физлиц может иметь ограничения на коммерческое использование. Прочитайте условия использования GigaChat API в кабинете. Если для продажи услуг нужен тариф для ИП или компаний, в файле `.env` смените `GIGACHAT_SCOPE` на `GIGACHAT_API_B2B` и используйте ключ от такого проекта.

## Шаг 4. Первый запуск (10 минут)

1. В папке `contract-audit-api` дважды щёлкните **`start.bat`**.
2. Откроется Блокнот с файлом настроек. После `GIGACHAT_AUTH_KEY=` вставьте ключ из шага 3, без пробелов и кавычек:
   ```
   GIGACHAT_AUTH_KEY=MDE5YjM0...ваш-ключ...==
   ```
3. Сохраните (**Ctrl+S**) и закройте Блокнот.
4. Снова запустите **`start.bat`**. Первый раз он устанавливает всё нужное (2–5 минут), потом проверяет нейросеть. Должна появиться строка:
   ```
   OK: нейросеть подключена.
   ```
5. Откроется браузер со страницей http://localhost:3000. **Не закрывайте чёрное окно:** пока оно открыто, сервис работает.

Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее → Выполнить в любом случае». Если брандмауэр спросит про доступ Node.js к сети — разрешите.

## Шаг 5. Выдать себе код и проверить договор (5 минут)

1. Дважды щёлкните **`new-code.bat`**. Введите `5` (количество проверок), затем имя, например `ya`.
2. Скопируйте код вида `K7F2-9QXA`.
3. На странице http://localhost:3000 введите код, загрузите **свой настоящий договор**, выберите сторону и нажмите «Проверить договор».
4. Через 1–3 минуты появится отчёт. **Пришлите мне скриншот** — я подстрою промпт под ответы GigaChat.

## Шаг 6. Открыть сайт в интернете по адресу dogovor-audit.ru (30 минут + ожидание)

Сайт открывается через бесплатный туннель Cloudflare: ваш компьютер становится доступен по адресу домена, без «белого» IP и без настройки роутера.

**6.1. Подключить домен к Cloudflare (один раз):**
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. Нажмите **Add a domain** (или «Добавить сайт»), введите `dogovor-audit.ru` и выберите тариф **Free**.
3. Cloudflare покажет **два адреса NS-серверов** вида `xxx.ns.cloudflare.com`.
4. В личном кабинете регистратора, где вы купили домен, найдите **«DNS-серверы»** у домена `dogovor-audit.ru` и замените их на эти два адреса.
5. Подождите, пока Cloudflare напишет, что домен активен: обычно 1–2 часа, иногда до суток. Придёт письмо.

**6.2. Создать туннель (один раз):**
1. Дважды щёлкните **`setup-tunnel.bat`**. В первый раз он установит программу `cloudflared`. Затем закройте окно и запустите `setup-tunnel.bat` ещё раз.
2. Откроется браузер: войдите в Cloudflare, нажмите на `dogovor-audit.ru` → **Authorize**.
3. Скрипт сам создаст туннель и привяжет домен. В конце будет «Готово!».

**6.3. Дальше всё автоматически:** при каждом запуске `start.bat` открывается второе окно «Туннель» (его тоже не закрывайте), и сайт работает по адресу **https://dogovor-audit.ru** с замочком HTTPS.

Для Mac и Linux: `brew install cloudflared` (или пакет с сайта Cloudflare), затем
```bash
cloudflared tunnel login
cloudflared tunnel create dogovor-audit
cloudflared tunnel route dns dogovor-audit dogovor-audit.ru
cloudflared tunnel route dns dogovor-audit www.dogovor-audit.ru
```
`./start.sh` после этого сам запускает туннель.

## Шаг 7. Чтобы сайт не «засыпал»

- **Параметры → Система → Питание и спящий режим → «Переводить в спящий режим»: Никогда.** Экран можно выключать, компьютер — нет.
- Если компьютер перезагрузился, снова запустите `start.bat`.
- Чтобы сервис запускался сам после включения: нажмите **Win+R**, введите `shell:startup`, перенесите в открывшуюся папку **ярлык** на `start.bat` (правой кнопкой → «Создать ярлык»).

## Шаг 8. Вписать свои данные в оферту и политику

Откройте в Блокноте `public\oferta.html` и `public\privacy.html` и замените все `[ЗАПОЛНИТЬ: …]` своими данными: ФИО, ИНН (из «Мой налог»), e-mail, контакт и цены. Сохраните файлы и перезапустите `start.bat`. Пока остались незаполненные места, сервер напоминает о них при запуске.

Это черновики, а не проверенные юристом документы. Перед первыми продажами желательно показать их юристу.

## Как продавать проверки

1. Клиент платит вам переводом → вы формируете чек в «Мой налог».
2. Запускаете `new-code.bat`, вводите количество проверок и имя клиента.
3. Отправляете клиенту код и ссылку https://dogovor-audit.ru

Если проверка не удалась (битый файл, сбой нейросети), проверка автоматически возвращается на код.

## Обновление сервиса

Когда я внесу изменения, скачайте новый ZIP (шаг 2) и **перенесите из старой папки в новую**:
- папку **`data`** — там коды клиентов и отчёты;
- файл **`.env`** — там ваш ключ;
- `public\oferta.html` и `public\privacy.html`, если вы их заполнили.

Затем запустите `start.bat` из новой папки.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `Не найден Node.js` | Шаг 1, затем перезапустите компьютер |
| `ОШИБКА: нейросеть не отвечает` + `oauth 401` | Неверный ключ: скопируйте его заново в `.env`, без пробелов |
| `model ... not found` | Поменяйте `GIGACHAT_MODEL` в `.env` на одну из моделей, которые `start.bat` выводит в строке «Доступные модели» |
| На сайте «Сервис анализа временно недоступен» | Нет интернета или исчерпан лимит GigaChat. В чёрном окне будет `402` — нужно пополнить пакет в кабинете Сбера |
| Сайт не открывается по домену | Проверьте, что открыто окно «Туннель», а в Cloudflare домен в статусе Active |
| Любая другая ошибка | Скопируйте текст из чёрного окна и пришлите в чат |

## Что важно знать

- **Сайт работает, только пока включён компьютер** и открыто чёрное окно. Когда появятся постоянные клиенты, лучше перенести сервис на арендованный сервер (от ~300 ₽ в месяц, российский VPS) — инструкция в `README.md`.
- **Бесплатного лимита GigaChat** хватит на десятки проверок. Следите за остатком в кабинете developers.sber.ru.
- **Трафик проходит через Cloudflare** (компания из США, данные зашифрованы). Юридически это может считаться трансграничной передачей; уточните у юриста, нужно ли отражать это в уведомлении в РКН. При переезде на российский сервер этот вопрос отпадает.

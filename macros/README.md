# FlashMacro — макросы для клавиатуры и мыши

Программа для Windows на AutoHotkey v2 с собственным меню в тёмной теме.

Меню (`ui.html`) отрисовывает встроенный в Windows веб-движок: поэтому все кнопки, карточки и
панели закруглённые, с тенями и плавными переходами. `FlashMacro.ahk` и `ui.html` должны лежать
в одной папке.

## Установка

Скачай `install-FlashMacro.bat` и запусти двойным кликом. Установщик:

- поставит AutoHotkey v2, если его ещё нет;
- создаст на рабочем столе папку **FlashMacro** и ярлык;
- сразу откроет меню.

Свой `config.ini` установщик не трогает, так что настройки сохраняются при обновлении.

## Меню

| Страница | Что там |
|---|---|
| **Dashboard** | Клавиатура и мышь с подсветкой: красным — клавиши запуска, синим — вкл/выкл макросов, зелёным — вкл/выкл прицела, белым — то, что прямо сейчас нажимает макрос. Ниже карточки макросов: клик по клавише на карточке меняет её, тумблер включает макрос. |
| **Keybinds** | Твои бинды из Fortnite и кнопка **Import from Fortnite**. |
| **Macros** | Настройки каждого макроса: задержки, способ подтверждения, FPS и прочее. |
| **Custom** | Свои макросы из любых нажатий: один раз, пока держишь или вкл/выкл. |
| **Crosshair** | Прицел поверх игры с живым превью: стиль, цвет, размеры, сдвиг. |
| **Remap** | Переназначение клавиш: одна клавиша нажимает другую (например, MB4 → Shift). |
| **Optimize** | Оптимизация Windows под игру, очистка кэша, тяжёлые фоновые программы (подробнее ниже). |
| **Configs** | Профили настроек: создать, переключить, переименовать, скопировать, сохранить в файл и загрузить из файла, сбросить макросы/бинды/прицел. |
| **Settings** | Язык (русский / English), клавиша вкл/выкл, режим «только в Fortnite», лог нажатий, удержание клавиш, темы оформления (6 цветов акцента и 3 варианта фона). |
| **License** | Ввод ключа, тариф и срок действия, проверка и продление. |
| **Support** | Подсказки. |

Сверху есть переключатель **MACROS ON/OFF** (по умолчанию на клавише `PgDn`).
Кнопка × сворачивает программу в трей, макросы при этом продолжают работать.
Меню снова открывается кликом по иконке в трее.

Если задержать курсор на любом элементе, появится подсказка на русском, что он делает.

- **Insert** (меняется в Settings) открывает меню поверх Fortnite и возвращает обратно в игру.
- Клик по клавише на клавиатуре или кнопке мыши на Dashboard показывает, что на ней висит,
  и позволяет сразу назначить её на любой макрос, бинд или системную функцию.
- Профиль переключается из шапки меню.
- На карточках виден счётчик срабатываний, карточка вспыхивает, когда макрос срабатывает.
- Прицел: 8 стилей (в том числе круг и крест в круге), обводка, прозрачность, свой цвет.
- Свой цвет акцента меню — полоса выбора цвета в Settings.

## Подписка и ключ

Тарифы: 1 месяц — $8.99 / 849 ₽, 3 месяца — $19.99 / 1890 ₽, навсегда — $49.99 / 4790 ₽.
Цены заданы в трёх местах: `flashmacro-server/server.js` (`PLANS`), сайт (`PRICES`) и
`ui.html` (`buildLicense`).

- Ключ вида `FM-XXXX-XXXX-XXXX-XXXX` приходит на почту и показывается на странице после оплаты.
- Вкладка **License** проверяет ключ на сервере при запуске и раз в 6 часов и привязывает его к ПК.
- Без интернета программа работает ещё 72 часа после последней удачной проверки.
- Без ключа работают меню и Optimize, а макросы, переназначения и прицел выключены.
- Адрес сервера задаётся в `LICENSE_API` в начале `FlashMacro.ahk` (или `[License] Api=` в
  `config.ini`). Пустое значение отключает проверку лицензии.

Сервер оплаты лежит в `flashmacro-server/` (Node 22): Stripe для долларов с автопродлением,
ЮKassa для рублей, письма через Resend. Все ключи — в `.env` (пример в `.env.example`).
Тестовый прогон без денег: `DEV_FAKE_PAY=1 npm start`, проверка: `npm test`.

## Язык

Меню и подсказки переводятся на английский в **Settings → Язык**. При первом запуске язык
выбирается по языку Windows. На сайте переключатель RU/EN в шапке.

## Макросы

Drag edit, Infinite edit, Instant edit, Instant build (в том числе непрерывная стройка),
Wall retake, Prefire, Sprint reset, Mantle, Simple edit, Crouch peek, Pick-up,
Auto sprint, Competitive mode, Rapid fire, Anti-AFK, а также сколько угодно своих макросов

## Optimize — как это работает

Каждый пункт — переключатель. Перед изменением FlashMacro сохраняет старое значение в
`config.ini` (секция `[OptBackup]`), а кнопка «Вернуть как было» откатывает только то, что
включал он сам. Пункты с жёлтой пометкой требуют запуска от имени администратора (в программе
есть кнопка перезапуска с правами).

| Пункт | Что меняет в Windows |
|---|---|
| Высокий приоритет Fortnite | `Image File Execution Options\FortniteClient-Win64-Shipping.exe\PerfOptions\CpuPriorityClass = 3`: игра каждый раз запускается с высоким приоритетом. |
| Схема питания | Создаёт и включает схему «Максимальная производительность» (`powercfg`), при выключении возвращает прежнюю. |
| Фоновая запись Xbox | `GameDVR_Enabled = 0`, `AppCaptureEnabled = 0`. |
| Игровой режим Windows | `GameBar\AutoGameModeEnabled`. |
| Точный таймер | `kernel\GlobalTimerResolutionRequests = 1` (Windows 10 2004+ / 11), после перезагрузки. |
| Планирование GPU | `GraphicsDrivers\HwSchMode = 2`, после перезагрузки. |
| Ускорение мыши | Отключает «Повышенную точность указателя» (то же, что галочка в настройках мыши). |
| Оптимизация во весь экран | Флаг совместимости `DISABLEDXMAXIMIZEDWINDOWEDMODE` для exe Fortnite. |
| Игровой режим FlashMacro | Пока запущен Fortnite: максимальная схема питания, высокий приоритет, таймер 0,5 мс; после выхода всё возвращается. |
| Лёгкий режим | Меню выгружается из памяти через 20 секунд после закрытия. |

Очистка удаляет временные файлы и кэш шейдеров DirectX/NVIDIA/AMD (занятые файлы пропускаются).
Список тяжёлых программ не закрывает ничего без подтверждения.

## Тест без игры

1. **Settings**: выключи «Работать только в окне Fortnite» и включи «Лог нажатий».
2. Открой Блокнот и нажимай клавиши запуска. Лог появится в Settings справа, а на Dashboard
   подсветятся клавиши, которые нажимает макрос.
3. После теста верни обе настройки обратно.

В самом окне FlashMacro макросы не срабатывают, чтобы не мешать вводу.

## Настройки Fortnite

- **«Подтверждать редактирование при отпускании»**: ВКЛ. Либо включи Competitive mode.
- **«Турбо-строительство»**: ВКЛ (нужно для непрерывной стройки).
- Для прицела режим окна должен быть **«Оконный полноэкранный»**.

> ⚠️ Epic запрещает макросы в турнирах и соревновательных режимах.

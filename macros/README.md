# FlashMacro — макросы для клавиатуры и мыши

Скрипт на AutoHotkey v2 для Windows. Повторяет функции KBM-макросов:
Drag Edit, Instant Edit, Infinite Edit, Instant Build (в том числе непрерывная стройка),
Auto Sprint, Pick-up, свои макросы (once / repeat / toggle), боевые пресеты
(Prefire, Wall Retake, Simple Edit, Crouch Peek, Mantle), прицел поверх экрана,
задержки и скорость для каждого макроса.

Ввод идёт через стандартный `SendInput` Windows, в игру ничего не внедряется.

> ⚠️ Epic запрещает макросы в турнирах и соревновательных режимах. Если играешь
> на основном аккаунте, есть риск бана, и он на тебе.

## Установка

1. Поставь **AutoHotkey v2**: https://www.autohotkey.com/ (именно v2, не v1).
2. Скачай папку `macros` (`FlashMacro.ahk` и `config.ini` должны лежать рядом).
3. Открой `config.ini` и впиши в `[Game]` свои бинды из Fortnite.
4. Запусти `FlashMacro.ahk` двойным кликом. В трее появится зелёная иконка **H**.

Меню в трее: открыть config, перезагрузить настройки, пауза, прицел, выход.
`F8` ставит все макросы на паузу и снимает с неё.

## Тест без игры (сначала так)

1. В `config.ini` поставь `OnlyInGame=0` и `Debug=1`, затем перезагрузи настройки.
2. Открой Блокнот или любой онлайн-тестер клавиатуры и мыши.
3. Нажми `g` (Drag Edit). Слева вверху появится лог, например
   `g down → g up → LButton down …`, а при отпускании `LButton up`.
4. Включи остальные макросы (`Enabled=1`) и проверь каждый так же.
5. Когда всё работает, верни `OnlyInGame=1` и `Debug=0`.

## Настройки в Fortnite

- **Подтверждать изменения при отпускании**: ВКЛ (для `ConfirmBy=release`).
  Если выключено, поставь в config `ConfirmBy=key`.
- **Турбо-стройка**: ВКЛ (для `Continuous=1`).
- Для прицела режим окна должен быть **«Оконный полноэкранный»**. В обычном
  полноэкранном режиме оверлей не видно.

## Если не срабатывает в игре

- Увеличь `EnterDelay`, `PlaceDelay`, `KeyHoldMs` и `ClickHoldMs` до 15–20 мс.
  При низком FPS игра не успевает обработать слишком быстрые нажатия.
- Запусти скрипт от имени администратора (ПКМ → «Запуск от имени администратора»).
- Проверь, что `GameExe` совпадает с процессом игры в Диспетчере задач.

## Чего пока нет

- **Импорта биндов из Fortnite**: игра хранит их в бинарном файле, поэтому бинды
  нужно вписать в `[Game]` руками.
- **Competitive Mode** (подглядывание сквозь конус во время редакта): сначала
  проверим базовые макросы на твоём ПК, потом добавлю.

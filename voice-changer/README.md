# Voice Changer

Программа для ПК, которая меняет голос в реальном времени: микрофон → эффекты → динамики или виртуальный микрофон (Discord, игры, OBS, Zoom).

## Возможности

**32 голоса**, которые реально отличаются друг от друга: программа меняет не только высоту тона, но и **форманты** (тембр, «размер головы»), поэтому женский или детский голос не звучит как ускоренная запись.

| Группа | Голоса |
|---|---|
| Люди | Обычный, Женский, Мужской, Ребёнок, Подросток, Бас, Старик, Бабушка, Диктор, Нервный |
| Персонажи | Великан, Гном, Эльф, Бурундук, Мультяшка, Демон, Монстр, Зомби, Злодей в маске, Призрак |
| Техника | Робот, Андроид, Инопланетянин, Ретро 8-бит, Рация, Телефон, Мегафон |
| Атмосфера | Шёпот, Под водой, Хор, Пещера, Собор |

**Громкость и чёткость** — четыре режима: «Обычная», **«Чёткая»** (для тихой речи: подтягивает тихие слова и делает голос разборчивым, не оглушая — включена по умолчанию), «Громкая» и «Максимум». В тонких настройках:
- **Улучшение голоса** — убирает гул и «бубнение», добавляет разборчивость и «воздух», компрессор выравнивает тихие и громкие слова;
- **Усиление** до +30 дБ;
- **Лимитер** — даже на максимуме голос не хрипит и не «клипует»;
- кнопки **🔊 Громкий и чистый голос**, **🔊🔊 Максимум** и **Сбросить**;
- при смене голоса настройки громкости сохраняются.

**Ручные настройки:** высота тона, тембр, шёпот, дрожание, глухость, робот, 8-бит, рация, искажение, хор, эхо, реверберация, шумодав.

Также есть режим обработки WAV-файлов без интерфейса.

## Установка на ПК (Windows 10/11) — одним файлом

1. Скачайте **`install.bat`** и запустите двойным щелчком.
   Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
2. Установщик сам:
   - поставит Python 3.12, если его нет (без прав администратора);
   - скачает программу в `%LOCALAPPDATA%\VoiceChanger`;
   - установит библиотеки;
   - создаст ярлык **Voice Changer** на рабочем столе и в меню «Пуск»;
   - предложит сразу скачать и установить VB-Cable для Discord и игр.
3. Запускайте программу ярлыком **Voice Changer**.

- Если программа не открывается: `%LOCALAPPDATA%\VoiceChanger\debug.bat` покажет ошибку.
- Удаление: `%LOCALAPPDATA%\VoiceChanger\uninstall.bat`.
- Повторный запуск `install.bat` обновляет программу до последней версии.

### Вручную

```
pip install -r requirements.txt
python voice_changer.py
```

Или `run.bat`. Чтобы собрать один файл `VoiceChanger.exe`, запустите `build_exe.bat` — результат появится в папке `dist`.

## Эквалайзер

Вкладка **«Эквалайзер»** — 8 полос, чтобы настроить собственный голос: Бас, Тело, Тепло, Нос (гнусавость), Середина, Разборчивость, Чёткость, Воздух.

- Готовые настройки: Радио-голос, Тёплый, Глубже, Яркий, Без гнусавости, Без бубнения, Без шипения, Подкаст.
- **«Подобрать под мой голос»** — нажмите «Старт» и говорите 6 секунд: программа сравнит ваш голос со средним спектром приятной речи и мягко поправит (не больше ±6 дБ), например уберёт гнусавость или добавит чёткости.
- Переключатель «Эквалайзер» — выключите, чтобы сравнить «до» и «после».
- Эквалайзер работает и при выключенном изменении голоса (F8), и вместе с любым голосом. На телефоне — то же самое, подбор по сделанной записи.

## Включить / выключить изменение голоса

Переключатель под названием голоса или клавиша **F8** (работает и в игре, и в Discord): выключено — вас слышат обычным голосом (чёткость и громкость сохраняются), включено — выбранным голосом. Программу останавливать не нужно.

## Как использовать голос в Discord / играх

1. Запустите **`install_vbcable.bat`** — он скачает бесплатный драйвер VB-Audio Virtual Cable с официального сайта и установит его (попросит права администратора). Перезагрузите компьютер.
2. В Voice Changer нажмите **Discord и игры** — вывод сам переключится на `CABLE Input`.
3. В Discord: Настройки → Голос и видео → **Устройство ввода** — `CABLE Output (VB-Audio Virtual Cable)`. В играх и OBS — так же.
4. Нажмите **▶ Старт**. Переключатель «Слышать себя в наушниках» — чтобы вы тоже слышали свой новый голос.

**Если Discord не слышит:** нажмите в программе «Проверить кабель» и «Настроить Discord». Самые частые причины: Discord не перезапускали после установки VB-Cable; в Discord выбрано «По умолчанию» вместо `CABLE Output`; включено шумоподавление Discord (Krisp) — оно вырезает изменённый голос, поставьте «Нет»; высокий порог чувствительности ввода.

Чтобы просто послушать себя, выберите в качестве вывода свои **наушники** (с колонками будет обратная связь и свист).

## Обработка файла

```
python voice_changer.py --file input.wav output.wav --preset "Робот"
python voice_changer.py --file input.wav output.wav --preset "Женский" --enhance 1 --boost 12
python voice_changer.py --list-presets
```

Поддерживаются 16-битные WAV.

## Если что-то не работает

- **Треск/заикание** — выберите устройства с пометкой `Windows WASAPI` или `MME`, закройте тяжёлые программы.
- **Ошибка при старте** — микрофон может быть занят другой программой или не поддерживать 48 кГц; попробуйте другое устройство из списка.
- **Своего голоса не слышно в Discord** — проверьте, что в Discord выбран `CABLE Output`, а в программе вывод `CABLE Input`.

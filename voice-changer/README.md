# Voice Changer

Программа для ПК, которая меняет голос в реальном времени: микрофон → эффекты → динамики или виртуальный микрофон (Discord, игры, OBS, Zoom).

## Возможности

- **Пресеты:** Обычный, Бурундук, Ребёнок, Великан, Демон, Робот, Инопланетянин, Рация, Пещера
- **Ползунки:** высота тона (±12 полутонов), робот, рация, искажение, эхо, шумодав, громкость
- Выбор микрофона и устройства вывода, индикатор уровня
- Режим обработки WAV-файлов без интерфейса

## Установка и запуск (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) — при установке отметьте **Add Python to PATH**.
2. Запустите `run.bat` (он сам поставит зависимости и откроет программу).

Или вручную:

```
pip install -r requirements.txt
python voice_changer.py
```

Чтобы собрать один файл `VoiceChanger.exe`, запустите `build_exe.bat` — результат появится в папке `dist`.

## Как использовать голос в Discord / играх

1. Установите бесплатный виртуальный кабель **VB-Audio Virtual Cable**: https://vb-audio.com/Cable/
2. В Voice Changer: **Микрофон** — ваш настоящий микрофон, **Вывод** — `CABLE Input`.
3. В Discord (или игре): **Устройство ввода** — `CABLE Output`.
4. Нажмите **▶ Старт**.

Чтобы просто послушать себя, выберите в качестве вывода свои **наушники** (с колонками будет обратная связь и свист).

## Обработка файла

```
python voice_changer.py --file input.wav output.wav --preset "Робот"
python voice_changer.py --list-presets
```

Поддерживаются 16-битные WAV.

## Если что-то не работает

- **Треск/заикание** — выберите устройства с пометкой `Windows WASAPI` или `MME`, закройте тяжёлые программы.
- **Ошибка при старте** — микрофон может быть занят другой программой или не поддерживать 48 кГц; попробуйте другое устройство из списка.
- **Своего голоса не слышно в Discord** — проверьте, что в Discord выбран `CABLE Output`, а в программе вывод `CABLE Input`.
